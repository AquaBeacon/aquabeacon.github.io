概要仕組み研究・結果つくる・使う公開資料軌跡とマップ

つくる・使う

基板と機構から、ファームウェア、解析まで。目的に合う資料を選び、各リポジトリの手順と対象バージョンを確認できます。

導入の順序

  1. システムの構成と接続を設計資料で確認する。
  2. 基板と機構の対象モデルを選び、製造・組立の資料を読む。
  3. 基板の確認用ファームウェア、または実験用の統合ファームウェアを目的に応じて選ぶ。
  4. 取得した記録の解析や、真値付きシミュレーションに進む。

構成や試作段階は資料ごとに異なります。対応するリポジトリのREADMEとセットアップ手順を確認してください。

公開資料を見る →

基板

親機・子機の回路図、PCB、製造用ツールを公開しています。基板の版と接続先を確かめてから、回路図とコネクタ表を参照してください。

  • 基板・回路資料
  • GPIO・コネクタ表
  • 初期音響回路の設計資料

機構

親機・子機の筐体や内装、組立モデル、印刷用部品を公開しています。構成によって部品の組合せが異なり、試作・未検証の項目もあります。

  • 組立モデルと印刷一式
  • 部品の一覧

ファームウェア

基板単体の確認と、実験時の記録には別のファームウェアを使用します。基板版、ピン割当、給電条件をそれぞれの手順で確認してください。

  • firmware：親機・子機メイン基板の動作確認用。
  • firmware-experiments：実験で使用した親機・子機・Spresenseの統合ファームウェア。
  • acoustic-tests：音響送受信・波形・同期の試験用。

解析

記録したセンサデータと映像から位置推定やマッピングを行います。データの形式、解析条件、適用範囲は各仕様とレポートを参照してください。

  • 解析ソフトウェア
  • 位置推定とマッピングの手法
  • 研究レポート

シミュレーション

真値付きの測位・マッピングシミュレーションで、条件を変えた検討ができます。モデルの前提と実行方法は数理仕様とREADMEを確認してください。

  • シミュレーション
  • 数理仕様
