OPEN SOURCE / UNDERWATER POSITIONING

Locate underwater.With light and sound.

AquaBeacon is an open-source project in development that combines light and sound for underwater positioning and mapping.

Explore AquaBeacon on GitHub ↗

Opening up underwater
positioning technology.

Connecting a surface unit with an underwater unit, AquaBeacon uses sound to measure distance and light to sense direction. The project aims to support positioning and mapping in underwater environments, including seagrass beds.

Software, hardware designs, and validation documentation are public and under active development.
