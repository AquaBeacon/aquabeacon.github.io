研究・結果 / 手法

METHOD / LIGHT + SOUND + ATTITUDE

光で方向を。
音で距離を。

水上の親機が水中の子機を観測します。光源の方向と音響の距離に、両機の姿勢・取付け位置・時刻を対応付け、親機に対する子機の位置を求めます。

以下は2026年11月1日10:15の静止評価に用いた処理です。マッピングの最終手法と結果は解析後に追記します。

観測から相対位置まで

  1. 音の到達時間から距離を求める

    親子機で時刻を対応させ、音の到達時間から親子の音響測定点間の距離を計算します。この解析では音速1500 m/s、時間オフセット0 µsを使用しています。音響距離は斜距離で、水圧から求めた深度とは区別します。

  2. 親機カメラで子機の光源を追跡する

    画像で対象の光源を確認し、10 Hzの画像でLucas–Kanadeの前後整合、固定テンプレートとのNCC照合、局所光源の重心を組み合わせて追跡します。追跡を失った箇所は欠測とし、再捕捉・目視点による再初期化を記録します。予測は探索にだけ使用し、予測座標を観測に混ぜません。

  3. 画素の方向と機体の姿勢をそろえる

    水中カメラの内部校正と歪み補正を用いて光点を方向に変換し、カメラと機体の取付け回転、IMUの姿勢、磁気方位の補正を通して共通の真ENU座標系（東・北・上）へ移します。カメラ・ライト・音響振動子・機体原点の位置の違いも考慮します。

    水中内部校正は暫定値です。CAD参照点・取付け・磁気方位にも未校正の要素があり、確定精度を保証する条件とは扱いません。

  4. 同じ時刻の観測を対応付ける

    有効な測距イベントごとに、時刻差75 ms以内の追跡画像を1枚対応付けます。同じ測距を重複して数えず、測距時刻の姿勢で位置を計算します。相対ベクトルは親機の機体原点から子機の機体原点までとし、両機に共通するGNSSの平行移動は差し引かれます。

静止RMSEは、何を表すか

各系列の平均位置を基準に、位置のばらつきを二乗平均平方根で求めます。3Dでは東・北・上の3成分、水平では東・北の2成分を使います。

3D RMSE = √{ (1/N) Σ ‖rᵢ − r̄‖² }
rᵢ：親機に対する子機の相対位置、r̄：その系列の区間平均、N：採用点数。

姿勢補正ありと、親機の回転のみを区間平均へ固定した比較条件に、同じ距離・光点・子機姿勢を使用します。それぞれの系列自身の平均まわりで算出し、平滑化やトレンド除去は行いません。

実際の動きや、光源同定・時刻同期・校正の誤差も含まれます。独立した位置真値に対する誤差ではなく、「絶対精度14 cm」とは表現しません。

位置推定からマッピングへ

子機が撮影した画像から水中環境の3D構造を再構成し、位置・姿勢の情報との対応を検証します。現在は解析中で、完成した地図・登録率・尺度・精度の結果は未掲載です。

画像だけで作る単眼再構成には任意尺度の断片が生じるため、そのままメートル単位の正しい地図とはみなしません。動く海藻・魚・気泡や未登録画像、欠測、位置拘束の条件も結果と一緒に記載します。
